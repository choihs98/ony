# Ony

키 이미지(원화) 중심의 2D 프레임 애니메이션 도구 (C++20 / Qt 6 / CMake). 프로젝트 파일 확장자: `.ony`

## 실행
- Windows: `build_windows.bat` (VS 2022 x64 Native Tools 프롬프트) → `dist\ony.exe`
- Linux:   `sudo apt install qt6-base-dev qt6-multimedia-dev cmake g++` →
           `cmake -S . -B build && cmake --build build -j && ./build/ony`
- 자체 테스트(Linux): `QT_QPA_PLATFORM=offscreen ./build/selftest`

## 처음 써보기
1. 파일 > 새 프로젝트 → 왼쪽 메인 패널에서 획 도구 → 캔버스에 그리기
2. 타임라인에서 프레임 클릭 → 다른 프레임에 그리기 (이미지가 없으면 직전 이미지를 홀드)
3. Enter 로 재생, L 로 라이트 테이블, 스페이스 누른 채 드래그로 화면 이동

이전 이름(`.tvpx`)으로 저장한 파일도 열 수 있습니다.

## 다른 PC에 설치 파일로 배포 (서명 없음)
- GitHub 에 올린 뒤 Actions > "Windows 설치 파일 빌드" > Run workflow → 끝나면 Artifacts 의 `Ony-Setup` 다운로드
  (안에 `Ony-Setup.exe`). 또는 PC 에 Inno Setup 6 이 있으면 `build_windows.bat` 이 `release\Ony-Setup.exe` 도 만듭니다.
- 서명이 없어서 처음 실행 때 Windows SmartScreen 이 경고합니다: "추가 정보" → "실행".

## 필압 조절
도구 패널의 「필압 사용」 아래에 조절 항목이 붙는다 (필압을 켜야 쓸 수 있다).
- **굵기 / 진하기** — 필압이 무엇에 작용할지 고른다. 둘 다 끌 수도 있다.
- **최소 굵기 (0~100%)** — 가장 약하게 눌렀을 때의 굵기. 0% 면 선이 점으로 사라지고,
  100% 면 필압이 굵기에 영향을 주지 않는다. 기본 6%.
- **최소 진하기 (0~100%)** — 가장 약하게 눌렀을 때의 진하기. 기본 0%.
- **감도 (-100 ~ +100)** — 음수로 갈수록 살짝만 눌러도 굵고 진하게, 양수로 갈수록 꾹 눌러야 나온다.
  기본 -35 (살짝 눌러도 잘 반응한다). 0 이 태블릿이 준 값 그대로다. 양 끝(0 과 1)은 감도와 상관없이 그대로이고, 어떤 값에서도
  누를수록 커지는 순서는 뒤집히지 않는다.
- 아래의 띠는 미리 보기다. 왼쪽이 살짝 누른 쪽, 오른쪽이 꾹 누른 쪽이다.
- 이 설정은 프리셋을 바꿔도 그대로 남고, 프로그램을 껐다 켜도 이어진다.

## 데모8
1. **캔버스 회전** — 보기 메뉴. Ctrl+Shift+, / Ctrl+Shift+. 로 15° 씩, Ctrl+Shift+0 초기화,
   「캔버스 각도 지정...」으로 숫자 입력. 화면만 돌고 그림·저장 결과는 그대로다.
   캔버스 위 정보줄의 각도는 하드코딩 `0°` 였는데 이제 실제 값을 보여 준다.
   각도가 0 일 때는 예전과 똑같은 길로 그려서 속도 차이가 없다.
2. **멀티플레인 카메라** — 레이어 메뉴 > 「멀티플레인 (카메라 따라가기)」.
   깊이를 **따라가기 %** 로 둔다: 100 = 기준면(카메라와 똑같이), 50 = 배경처럼 절반만,
   150 = 앞쪽처럼 더, 0 = 아예 안 따라감. 프리셋 7개 + 직접 입력. 프로젝트에 저장된다.
   모든 레이어가 100 이면 예전 합성 경로 그대로다.
3. **자동 채색 (일괄)** — 이미지 메뉴. 페인트통으로 칠한 자리·색을 기억해 두었다가
   고른 구간의 다른 프레임에 그대로 다시 칠한다. 그림이 있는 프레임(키)만 칠하고
   홀드 중인 칸은 건너뛴다. 비슷함 범위를 조절할 수 있고, 되돌리기 한 번으로 전부 되돌아간다.
4. **애니메이션 브러시** — 레이어 메뉴 > 사용자 브러시 · 질감.
   그림 파일 여러 장으로 만들거나, 현재 레이어의 이미지들로 만든다(빈 가장자리는 잘라낸다).
   찍을 때마다 다음 장이 나오고, 도구 패널에서 차례대로 / 무작위를 고른다.
5. **배치 렌더** — 파일 메뉴 (Ctrl+Shift+B). 형식·범위·크기·카메라·소리·투명 배경을 정해
   작업을 여러 개 걸어 두고 위에서부터 처리한다. 진행 막대와 성공·실패 표시가 있고,
   닫기를 누르면 지금 작업만 끝내고 멈춘다. 걸어 둔 목록은 창을 닫아도 남는다.
6. **편집용 내보내기 (EDL / XML)** — 파일 메뉴. 북마크로 컷을 나누고 프레임 메모를 컷 이름으로 쓴다.
   CMX3600 EDL 과 Final Cut 7 식 XML(프리미어도 읽는다)을 쓴다.
7. **컬러 프로필 (ICC)** — 프로젝트 설정. sRGB / Display P3 / Adobe RGB / ProPhoto RGB / 붙이지 않음.
   내보내는 PNG·JPG·TIFF 에 프로필로 붙는다. 픽셀 값은 바꾸지 않는다.

## 배포 방식 세 가지
GitHub Actions 가 한 번에 세 가지를 만든다.
- `Ony-Setup.exe` — 설치 프로그램. Program Files 에 설치하고 바탕화면 바로가기를 만든다.
  `.ony` 파일 연결이 되고 가장 빨리 뜬다. 바로가기에는 Windows 가 화살표를 붙인다.
- `ONY-Portable.exe` — 단일 실행 파일. 설치 없이 아무 데나 두고 바로 실행한다.
  바로가기가 아니라 화살표가 없다. 실행할 때마다 임시 폴더에 풀어서 뜨는 데 오래 걸린다.
- `ONY-Portable.zip` — 폴더째 쓰는 판. 풀어서 ony.exe 를 실행한다. 설치가 필요 없고 속도는 설치판과 같다.
